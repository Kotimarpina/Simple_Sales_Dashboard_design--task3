# Task 3 – Sales Dashboard Design

## 📌 Overview

This project is completed as part of the **Veda Technologies Data Analytics Internship**. The objective of this task is to transform cleaned sales data into an interactive dashboard that provides a clear view of sales performance across products, regions, and time.

The dashboard was developed using **Microsoft Power BI** and is designed to provide stakeholders with a simple and interactive way to explore sales performance and identify important trends.

## 🎯 Objectives

- Analyze overall sales performance
- Compare sales across different products
- Analyze regional sales performance
- Identify sales trends over time
- Present important KPIs in a concise format
- Provide interactive filtering using slicers
- Convert raw/cleaned data into a stakeholder-friendly dashboard

## 🛠️ Tools Used

- Microsoft Power BI
- Excel
- Power BI Data Visualization
- Power BI Slicers and Filters

## 📊 Dashboard Features

The dashboard includes:

- **Sales KPI Cards** for quick performance overview
- **Sales by Product** visualization
- **Sales by Region** visualization
- **Sales Trend over Time** visualization
- **Interactive slicers/filters**
- Consistent formatting and visual design
- Interactive cross-filtering between visuals

## 🔍 Key Analysis Areas

### 1. Product Performance
Analyzes sales contribution across different products and helps identify differences in product-level performance.

### 2. Regional Performance
Compares sales across regions to understand geographic differences in business performance.

### 3. Time-Based Analysis
Shows how sales change over time and helps identify periods of higher or lower sales activity.

### 4. KPI Analysis
Provides a high-level overview of important business metrics before moving into detailed visual analysis.

## 🎛️ Interactivity

The dashboard includes slicers and filters that allow users to dynamically explore the data.

Users can:

- Filter by region
- Filter by month/time period
- Combine multiple filters
- Observe changes across connected visuals

This makes the dashboard interactive rather than a collection of static charts.
